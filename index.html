ABOUT JMAKESGAMES

🎮

I'm the one-person show behind JMakesGames. No studio, no team — just me, a code editor, and way too many hours spent tweaking pixel sprites at 2am. Every sound effect in these games is synthesized from scratch, every sprite is hand-drawn in canvas, and there's not a single external asset file anywhere. Pixel Dungeon Heroes started as a project I wasn't sure anyone would play, and somehow turned into a real game with real players and a real multiplayer mode. Now I'm deep in the sequel, throwing in everything I wished the first game had. Thanks for checking these out — and if you run into a bug, it's basically a hidden feature. (Tell me about it anyway.)
